WANDERLUST - JavaScript layer (drop into the original starter)

1) Copy the 4 files in src/js (main.js, api.js, core.js, views.js) into the starter's src/js folder. Replace the empty main.js.
2) Do NOT touch index.html or src/css.
3) Open the starter folder in VS Code and run "Go Live" (Live Server). ES modules need http, not file://.
4) API keys:
   - Ticketmaster (Events): paste your key in src/js/api.js -> CONFIG.TICKETMASTER_KEY (the key is in the Postman collection). Without it, Events show sample data and a notice.
   - Country details use countries.dev (no key; browser CORS enabled). Nager.Date, Open-Meteo, open.er-api.com, Sunrise-Sunset, and FlagCDN need no key.
5) Routes: #/dashboard #/holidays #/events #/weather #/long-weekends #/currency #/sun-times #/my-plans
